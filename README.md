# HADA 콘텐츠 스튜디오

카드뉴스 · 숏폼 · 스레드 · 블로그를 한곳에서 만드는 프로그램입니다.
이곳은 **설치 파일을 내려받는 곳**입니다.

---

## ⬇️ 내려받기 (Windows)

1. 오른쪽 **Releases** → 맨 위 **최신 버전** 클릭
2. 아래 **Assets** 에서 **`HADA-Content-Studio-Setup-버전.exe`** 를 받습니다

## 설치하기

1. 받은 `.exe` 파일을 더블클릭
2. 파란 창 **"Windows의 PC 보호"** 가 뜨면 → **추가 정보** → **실행**
3. **설치** 를 누르면 끝입니다 (관리자 권한 필요 없음)
4. 바탕화면의 **HADA 콘텐츠 스튜디오** 로 실행합니다

## 처음 켰을 때

**⚙ 채널·설정 → API 키** 에 본인의 Gemini 키를 넣어주세요. (발급: https://aistudio.google.com/apikey)

## 업데이트

새 버전 설치 파일로 **다시 설치하면** 됩니다. 채널·키·원고 등 작업한 내용은 **그대로 남습니다.**
